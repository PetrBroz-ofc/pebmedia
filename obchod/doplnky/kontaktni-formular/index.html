Kontaktní formulář

Čistě vystylovaný kontaktní formulář (jméno, e-mail, zpráva) bez vlastního backendu. V README je návod, jak ho během pár minut napojit přes službu Formspree, nebo na vlastní serverless endpoint.

  • Validace polí na straně prohlížeče (povinná pole, formát e-mailu)
  • Přístupné popisky a chybové hlášky pro čtečky obrazovky
  • Návod na napojení: Formspree (bez kódování) i vlastní endpoint
  • V balíčku: index.html (ukázka), styl.css, skript.js, README.md, LICENCE.txt
  • Pro koho: pro webaře a ty, kdo si web upravují sami — vložení vyžaduje základní znalost HTML a CSS. Na stavebnicích typu Wix nebo Webnode ho většinou vložit nejde.

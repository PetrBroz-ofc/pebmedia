Sada tlačítek a odznaků

Sada stylovaných tlačítek (primární, sekundární, obrysové) a odznaků (badges) v několika barevných variantách. Hotové ke zkopírování do libovolného webu.

  • Varianty tlačítek: plné, obrysové, textové, s ikonou
  • Odznaky pro stavy (novinka, sleva, aktivní, neaktivní apod.)
  • Jen čisté CSS třídy — žádný JavaScript ani závislosti
  • V balíčku: index.html (ukázka), styl.css, README.md, LICENCE.txt
  • Pro koho: pro webaře a ty, kdo si web upravují sami — vložení vyžaduje základní znalost HTML a CSS. Na stavebnicích typu Wix nebo Webnode ho většinou vložit nejde.
